# readable-shell for Pi

(audience: humans)

## What works

The adapter prints the rules when the first turn of a session starts, and hands
every tool call to the guard before it runs, so a command or a write to a shell
file that breaks the rules is refused. An edit making several replacements in
one call is checked like any other.

Verified at 0.1.1 on a real session: `git --version -q` and a write of `enc=1`
to `probe.sh` were refused with the guard's reason, and the same write to
`probe.md` ran.

## Installing

    pi install git:github.com/justinkek/readable-shell

The extension runs the plugin's hooks: the session start ones when the first
turn of a session starts, the prompt ones on every turn after that, and the
stop ones when a turn ends.

## Updating

    pi update git:github.com/justinkek/readable-shell

## Uninstalling

    pi remove git:github.com/justinkek/readable-shell

    rm -rf ~/.readable-shell

That takes the settings and the state with it, so nothing is left.
