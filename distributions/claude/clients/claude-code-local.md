# readable-shell for Claude Code, on your machine

(audience: humans)

## What works

Every hook runs: the first shell file a session writes is refused once with the
rules, and a write that breaks them after that is refused before it runs. Settings are
kept in `~/.readable-shell`, or in a project's own `.readable-shell/settings`.

Not yet verified on a real session.

## Installing

    claude plugin marketplace add justinkek/readable-shell
    claude plugin install readable-shell@readable-shell

(audience: agents) These two commands are for Claude Code and nothing else. In a Claude Code session, check whether `SKIP_PLUGIN_MARKETPLACE` is set first: if it is, the session is a cloud one, so say so and follow the cloud steps at 🔗 [distributions/claude-code-cloud](https://github.com/justinkek/readable-shell/tree/main/distributions/claude-code-cloud) instead.

## Updating

    claude plugin marketplace update readable-shell
    claude plugin update readable-shell@readable-shell

Load the new copy into a session already running by restarting it or running
`/reload-plugins`.

If the version does not move, the marketplace snapshot is stale: the first of
the two commands failed or was skipped.

Your settings are in `~/.readable-shell` and no install touches them.

## Uninstalling

    claude plugin uninstall readable-shell@readable-shell
    claude plugin marketplace remove readable-shell
    rm -rf ~/.readable-shell

The last of the three takes the settings and the state with it, so nothing is
left.
