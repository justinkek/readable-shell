# readable-shell for Claude Chat

(audience: humans)

## What works

No hook runs, so nothing is refused and a session is never shown the rules.

Not yet verified on a real session.

## Installing

Open the plus menu beside the message box, then Plugins, then Browse plugins,
and install readable-shell. Its skills appear under the plugin's own entry
in that menu.

No hook runs in Chat, so nothing the plugin would print at session start
reaches a conversation on its own. Ask for the reload skill in your first
message and it prints it; a preference or a custom style holding the same text
does it without asking.

Nothing reads a settings file either, so a setting you ask for lasts as long as
that conversation does.

(audience: agents) You cannot do this part: the window is the person's to
click. Print these steps for them and stop.

## Updating

Open the plus menu, then Plugins, then Manage plugins, and update it there.

## Uninstalling

Open the plus menu, then Plugins, then Manage plugins, and remove it there.

Nothing here writes `~/.readable-shell`, so the removal leaves nothing behind.
